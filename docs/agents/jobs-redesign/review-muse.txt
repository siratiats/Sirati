- Parse anchors **only inside the message-text element**, never the post wrapper.
- **Deny:** `t.me`/`telegram.*`, Instagram, Snapchat, X/Twitter, Facebook, YouTube, hashtag-search URLs (`?q=%23…`), `chat.whatsapp.com` group invites, and any link in a repeated promo footer.

- **Shorteners** (`lik.ad`, `bit.ly`, …): resolve server-side with a timeout, re-validate the final host against the same rules; unresolved → `none`.
- **Email in text** → `apply_method: email`, `apply_email`; explicit “apply via WhatsApp + number” → `apply_method: whatsapp` (`wa.me/<number>`); a bare phone number is shown as text only, never auto-linked.
- API: `apply_method: url|email|whatsapp|none`, `apply_url` (non-null only for url/whatsapp), `apply_email`, `source_url` (the Telegram post), `source_label`.
